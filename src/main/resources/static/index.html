Documentação da API

Consultar endereço

GET /cep.api/{cep}

Use o formato 00000-000, com hífen. A resposta é em JSON e a rota dispensa autenticação.

curl http://localhost:8080/cep.api/01001-000
200
Endereço encontrado
400
CEP com formato inválido · INVALID_CEP
404
CEP não encontrado · CEP_NOT_FOUND
502
Falha no provedor · PROVIDER_UNAVAILABLE

Exemplo de resposta

  "cep": "01001000",
  "logradouro": "Praça da Sé",

  "localidade": "São Paulo",
  "uf": "SP"
